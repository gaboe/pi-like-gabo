# Workspace mutation execution audit

Runtime process/session launch surfaces owned by this super-plugin were audited for workspace-mutation lease interaction.

## Arbitrary or unconstrained routes

| Surface                                                                          | Classification                                                                           | Global protocol                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vendor/pi-tools/extensions/background-terminals/src/manager.ts` shell spawn  | Arbitrary user/agent command                                                             | Synchronous global shell reservation before spawn; active lease rejection; activity retained through settlement/kill/disposal; permanent shell taint, including failed spawn.                                                                                                                                    |
| `extensions/jobs/manager.ts` command jobs                                        | Arbitrary durable command monitor                                                        | Independent synchronous global shell reservation around backend lifetime. Background-terminal adapter adds its own reservation at actual spawn. Stop, settlement, failed start, resume cleanup, and disposal release exactly once.                                                                               |
| `vendor/pi-tools/extensions/subagents/src/manager.ts` Pi workers             | In-process Pi session                                                                    | Manager lifecycle and Pi guards retain capacity and workspace accounting through settlement and teardown.                                                                                                      |
| `vendor/pi-tools/extensions/git-info/src/process.ts` generic command runner   | Arbitrary executable/arguments at runner boundary; production uses Git metadata commands | Synchronous global shell reservation before process spawn; retained through output drain, exit, timeout interruption, and scoped process cleanup; permanent shell taint. This also covers Git-configured helper execution.                                                                                       |
| `vendor/pi-tools/extensions/subagents/index.ts` parent `tool_call` write/edit | Arbitrary parent file mutation                                                           | Target is resolved before reservation by one shared fail-closed resolver matching Pi 0.80.6 `resolveToCwd` semantics (Unicode spaces, one `@`, home, `file://`, absolute/relative cwd); invalid input blocks before tool body.                                                                                   |
| `vendor/pi-tools/extensions/subagents/index.ts` parent `tool_call` bash       | Arbitrary parent shell command                                                           | Synchronous process-global shell reservation before tool execution; active lease rejection; release on `tool_execution_end`/shutdown; permanent shell taint.                                                                                                                                                     |
| `vendor/pi-tools/extensions/subagents/index.ts` parent `user_bash`            | Arbitrary interactive shell command                                                      | Synchronous process-global shell reservation in `user_bash` before returned operations can execute; active lease returns a complete blocked result; release on exec settlement/shutdown; permanent shell taint.                                                                                                  |
| `vendor/pi-tools/extensions/subagents/src/manager.ts` Pi workers              | Managed agent session                                                                    | Existing canonical-root managed-worker registration plus process-global bash guard and write/edit guards. Write/edit use the same fail-closed Pi 0.80.6-parity resolver as parent tools before lease checks and body execution. Finding-fixer remains protected by exclusive lease and native mutation protocol. |
| `vendor/pi-tools/extensions/workflows/runner.ts` workflow agent sessions      | Unconstrained child agent with local bash/edit/write                                     | Process-global unconstrained-worker registration before session factory; retained through abort, child shutdown, and disposal; failed creation taints and releases.                                                                                                                                              |
| `extensions/btw/index.ts` persistent BTW coding session                          | Unconstrained in-process agent with bash/edit/write                                      | Process-global unconstrained-worker registration before session creation; retained until replacement, failure cleanup, or session shutdown; permanent unconstrained taint.                                                                                                                                       |

## Mechanically confined or fixed helper routes

| Surface                                                                           | Why it does not globally taint                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vendor/pi-tools/extensions/workflows/sandbox.ts` Node child                   | Permission mode grants read access only to sandbox bootstrap directory and grants no filesystem write, network, or child-process permission. Authenticated IPC exposes only phase metadata and host-side agent requests. Host agents are registered separately. |
| `vendor/pi-tools/extensions/subagents/src/safe-mutation.ts` native safe writer | Fixed bundled helper, descriptor-confined mutation protocol, invoked only under valid finding-fixer lease owner.                                                                                                                                                |
| `extensions/comment-checker/runner.ts` comment checker                            | Fixed plugin-relative pinned analysis binary with fixed `check` subcommand; not a user-selected command runner.                                                                                                                                                 |
| `vendor/pi-tools/extensions/copy-all/index.ts` `pbcopy`                        | Fixed clipboard binary; no workspace path or command input.                                                                                                                                                                                                     |
| `vendor/pi-tools/extensions/background-terminals/src/manager.ts` `taskkill`    | Fixed Windows process-tree cleanup helper; PID and fixed flags only.                                                                                                                                                                                            |
| `vendor/pi-tools/extensions/subagents/scripts/build-native.mjs` compiler spawn | Install/build script, not loaded extension runtime; fixed safe-writer source/output build.                                                                                                                                                                      |
| Test `execFile`/`spawn`/`spawnSync` sites                                         | Test-only fixtures and process-lifecycle assertions.                                                                                                                                                                                                            |

Network-only jobs (`websocket` and `poll`) execute no local commands and do not taint. `Symbol.for("my-pi-setup.workspace-mutation-lease.v1")` owns one process-global registry across module graphs; lease-owner validity derives from that shared registry rather than module-local branding. Protocol errors and shared state expose neither workspace roots nor owner tokens.

## Launch-site enumeration

Production runtime launch sites:

- `extensions/btw/index.ts`: two `createAgentSession` calls. Persistent coding session is globally registered; tool-less summarizer loads no extensions and cannot execute local commands or writes.
- `extensions/comment-checker/runner.ts`: fixed checker `spawn`.
- `extensions/jobs/manager.ts` and `extensions/jobs/background-terminal-adapter.ts`: arbitrary command lifecycle and background-terminal delegation; no second OS-spawn implementation.
- `vendor/pi-tools/extensions/background-terminals/src/manager.ts`: arbitrary shell `spawn` and fixed Windows `taskkill` cleanup `spawn`.
- `vendor/pi-tools/extensions/copy-all/index.ts`: fixed `pbcopy` `spawn`.
- `vendor/pi-tools/extensions/git-info/src/process.ts`: Effect `ChildProcessSpawner.spawn` generic command route.
- `vendor/pi-tools/extensions/subagents/index.ts`: parent `tool_call` write/edit use the shared fail-closed Pi 0.80.6-parity target resolver and path-aware reservation; parent `tool_call` bash and `user_bash` use synchronous process-global shell guards.
- `vendor/pi-tools/extensions/subagents/src/manager.ts`: backend session dispatch, globally registered before dispatch.
- `vendor/pi-tools/extensions/subagents/src/backends/pi.ts`: `createAgentSession` and nested-worker callback dispatch, covered by manager registration and managed guards; write/edit share parent resolver parity and reject invalid input before body.
- `vendor/pi-tools/extensions/subagents/src/safe-mutation.ts`: fixed native safe-writer `spawn` under lease.
- `vendor/pi-tools/extensions/workflows/runner.ts`: child `createAgentSession`, globally registered.
- `vendor/pi-tools/extensions/workflows/sandbox.ts`: permission-confined Node `spawn`.
- `vendor/pi-tools/extensions/subagents/scripts/build-native.mjs`: build-time compiler `spawnSync`, outside extension runtime.

Direct test-only process/session sites are `extensions/comment-checker/comment-checker.test.mjs`; manager/backend tests under `vendor/pi-tools/extensions/background-terminals` and `vendor/pi-tools/extensions/subagents`; `vendor/pi-tools/extensions/git-info/process.test.ts`; `vendor/pi-tools/extensions/shared/child-session.test.ts`; and runner/sandbox tests under `vendor/pi-tools/extensions/workflows`. Repository scan found no other plugin-owned `spawn`, `spawnSync`, `exec`, `execFile`, `fork`, Effect process spawner, or `createAgentSession` runtime site outside dependencies and documentation.
